# Mock API — Data Sementara untuk Develop UI/UX

Folder ini berisi file JSON **sementara** yang meniru respons endpoint API (lihat kontrak di [docs/architecture.md](../../docs/architecture.md) bagian 1.4).

| File | Meniru endpoint | Sumber data |
|---|---|---|
| `profil.json` | GET /api/profil | Resmi (docs/info.md) |
| `jurusan.json` | GET /api/jurusan | Resmi (docs/info.md), deskripsi draft |
| `ppib.json` | GET /api/ppib | **Contoh fiktif** |
| `prestasi.json` | GET /api/prestasi | **Contoh fiktif** |
| `alumni.json` | GET /api/alumni | **Contoh fiktif** |
| `mitra.json` | GET /api/mitra | **Contoh fiktif** |
| `produk.json` | GET /api/produk | **Contoh fiktif** |
| `lowongan.json` | GET /api/lowongan | **Contoh fiktif** |
| `pengumuman.json` | GET /api/pengumuman | **Contoh fiktif** |

⚠️ **Semua nama orang, perusahaan, angka, dan tanggal berlabel fiktif WAJIB diganti data riil sekolah sebelum website dipublikasikan.**

Path gambar menunjuk ke `/assets/img/placeholder/…` — siapkan gambar placeholder di situs publik, ganti dengan foto asli nanti.
