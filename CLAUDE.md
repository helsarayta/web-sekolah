# CLAUDE.md — Website SMKN 10 Semarang (Lomba Web Development)

Proyek website resmi **SMKN 10 SEMARANG OFFICIAL** untuk cabang lomba **Web Development**. Dokumentasi lengkap ada di folder `docs/` — baca kedua file di bawah ini sebelum mengerjakan fitur apa pun:

- **[docs/goals.md](docs/goals.md)** — target yang akan dicapai: latar belakang lomba, kriteria keberhasilan, 5 modul wajib (landing page, PPIB, BLUD, BKK/PKL, ChatBot AI), panduan pengembangan, dan glosarium istilah.
- **[docs/info.md](docs/info.md)** — informasi detail sekolah: data pokok (NPSN, alamat, kontak), sejarah, visi, 10 jurusan, fasilitas, dan media sosial resmi. Seluruh konten website harus konsisten dengan data di file ini.
- **[docs/architecture.md](docs/architecture.md)** — keputusan teknis: arsitektur situs publik (FINAL — vanilla HTML/CSS/JS + pre-render dari API) dan sisi management (masih dalam diskusi).

## Struktur Repositori

```
web-sekolah/
├── CLAUDE.md      # Dokumen ini — pintu masuk dokumentasi proyek
├── docs/
│   ├── goals.md         # Target & ruang lingkup lomba
│   ├── info.md          # Profil detail SMKN 10 Semarang
│   └── architecture.md  # Keputusan teknis (publik: FINAL, management: diskusi)
├── management/    # (rencana) area pengelolaan konten / admin
└── public/        # (rencana) aset & halaman publik website
```

> Catatan: folder `management/` dan `public/` masih kosong (tahap awal pengembangan). Perbarui bagian ini seiring struktur proyek berkembang.
